# Бенчмарки

Замеры в **jsdom**, не в браузере. Он завышает стоимость создания узлов и
особенно перемещений. Относительные позиции фреймворков передаёт, абсолютные
числа — нет.

## Запуск

```bash
cd .. && bun run build && cd bench   # бенчмарки читают dist/regan.js
npm install
bun run build-solid                  # один раз: Solid без своего babel не работает
```

### `bench.ts` — regan против React и Solid

```bash
bun run bench 500
bun run bench 2000
```

Список из N строк по два `<span>`, у каждой строки свой сигнал. Меряет
монтирование, обновление всех строк и обновление одной.

`--conditions=browser` внутри скрипта обязателен: без него Solid подтягивает
серверную сборку.

### `keyed.ts` — что дают ключи

```bash
bun run keyed 1000          # с ключами
bun run keyed 1000 nokey    # без ключей
```

Вставка в начало, удаление из середины, разворот списка. Кроме времени печатает
**сколько раз выполнилось тело компонента** — это и есть главный эффект ключей.

### `dommove.ts` — сколько стоит сам jsdom

```bash
bun run dommove
```

Разворот 1000 узлов голыми вызовами DOM, без regan. Нужен, чтобы отделить
собственный расход фреймворка от расхода среды: на развороте почти всё время
уходит сюда.

### `ctx.ts` — поля-стрелки против методов прототипа

```bash
bun run ctx
```

Микробенчмарк создания экземпляров. Под bun показывает разницу в десятки раз,
под node после разогрева JIT — никакой, а на реальном монтировании 2000 строк её
нет ни там, ни там: создание `Ctx` теряется на фоне остальной работы. Поэтому
`Ctx` оставлен со стрелками — они позволяют деструктуризацию.

Общее окружение (jsdom в глобальных объектах, замер среднего) — в `env.ts`, три
реализации списка — в `frameworks.ts`.

## Что получалось

N=500, пять прогонов, мс:

|       | монтирование | обновить все | обновить один |
| ----- | ------------ | ------------ | ------------- |
| solid | 11.0–12.0    | 0.62–0.90    | 0.002–0.006   |
| regan | 16.4–19.4    | 0.66–1.11    | 0.005–0.009   |
| react | 19.8–21.5    | 6.27–9.29    | 0.88–1.02     |

Список из 1000 строк с компонентом на строку:

| операция             | без ключей              | с ключами               |
| -------------------- | ----------------------- | ----------------------- |
| вставка в начало     | 10.2 мс / 1001 запуск   | 1.9–2.6 мс / 1 запуск   |
| удаление из середины | 10.2 мс / 1000 запусков | 1.3–1.6 мс / 0 запусков |
| разворот             | 9.2 мс / 1000 запусков  | 67 мс / 0 запусков      |

Разворот с ключами выглядит провалом, но 66 из 67 мс — это сам jsdom на
перемещении 1000 узлов (`dommove.ts`). Без ключей он «быстрый» только потому,
что ничего не двигается: узлы остаются на местах, а перерисовывается содержимое.
